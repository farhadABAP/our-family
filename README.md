This website is my main showcase project. It is a fully interactive, gamified learning platform designed to teach languages, math, and cultural values through engaging, age-appropriate modules.

### ✨ Website Features & Technical Highlights:

- 🧮 **Interactive Math Engine**: Custom-built arithmetic quizzes with dynamic difficulty levels (Easy, Medium, Hard), instant feedback, and a streak/score tracking system.
- 🌍 **Multilingual Modules**: 
  - 🇩🇪 **German**: Article quizzes (der/die/das), syllable counting, spelling, and sentence building.
  - 🇬🇧 **English**: Vocabulary matching, translation exercises, and basic sentence construction.
  - 🕌 **Arabic**: Full alphabet recognition, vocabulary, and a complete **Am-Para reader** featuring all 37 Surahs with Arabic text, translations, and prayer guides (Salah, Eid, Janaza).
  - 🇧🇩 **Bengali**: Alphabet introduction and word-matching games.
- 🎨 **Early Childhood Mode**: A colorful, simplified interface for kindergarten-level learning (colors, numbers 1-20, animals, and interactive songs).
- ⚡ **100% Vanilla Stack**: Built entirely with pure **HTML5, CSS3, and JavaScript**. No external frameworks or heavy libraries, ensuring lightning-fast load times and clean, maintainable code.
- 📱 **Fully Responsive**: Custom CSS grid and flexbox layouts that adapt seamlessly to desktop, tablet, and mobile screens.
- 🏆 **Gamification**: Local state management for tracking stars, daily correct answers, and unlocking achievements to keep users motivated.
